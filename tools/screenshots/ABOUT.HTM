Welcome to VibeOS

An experiment to see how far an AI can go in building an operating system for x86 PCs. It boots from a 1.44MB floppy disk and targets the 486.

What it has

  • Preemptive multitasking, user processes and a shell with pipes
  • A window system with a dock, and apps like this browser
  • FAT12 and TCP/IP: ping, get, httpd and browse
