VibeOS GUIDE
============

VibeOS is a small operating system for
32-bit x86 PCs. It boots from a 1.44MB
floppy disk. The screen is 640x480 with
256 colors (VESA), or 320x200 (VGA mode
13h) on older video cards.

SCREEN MODE
-----------
/BOOT.CFG chooses the mode:
  video=640x480  or  video=320x200
Edit it, sync, and reboot. Hold Shift
while booting to use 320x200 once.
Programs made for 320x200 are shown
twice as large in 640x480.

SHELL COMMANDS
--------------
help      list commands
clear     clear the screen
echo      print text
ls        list a directory
cat       print files
hexdump   dump a file in hex
cd, pwd   change / print directory
mem       memory usage
ps        list tasks
uptime    time since boot
date      current date and time
sleep     sleep for some milliseconds
history   command history
demo      three threads draw counters
write     write text to a file
append    add a line to a file
cp, rm    copy / remove files
mkdir     make a directory
df        free space, unsaved changes
sync      save changes to the floppy
beep      sound the PC speaker
reboot    restart the computer

LINE EDITING
------------
Left/Right, Home/End  move the cursor
Backspace/Delete      erase
Up/Down               history
Ctrl+C                cancel the line,
                      or stop a program
Ctrl+L                clear the screen

PROGRAMS (/BIN)
---------------
hello     greeting, arguments, heap
view      show a BMP image
paint     draw with the mouse
mandel    the Mandelbrot set
          (arrows move, + and - zoom)
snake     the snake game (arrows)
more      read a text file page by page
edit      text editor
          ^S save (and sync), ^Q quit,
          ^F find, ^G go to line,
          ^K cut line, ^U paste
fault     misbehave on purpose (tests)

Any name that is not a shell command is
looked up as /BIN/NAME.ELF.

FILES
-----
/KERNEL.SYS        the kernel
/HELLO.TXT         a greeting
/DOCS/README.TXT   about the documents
/DOCS/GUIDE.TXT    this guide
/IMAGES/PLASMA.BMP 8-bit image
/IMAGES/GRADIENT.BMP true color image

The disk is loaded into memory at boot
(a RAM disk). Changes stay in memory
until you type "sync", which writes the
changed sectors back to the floppy.
File names use the 8.3 form (NAME.EXT).
